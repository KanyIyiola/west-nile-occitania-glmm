# Environmental determinants of West Nile virus RNA detection in Occitania

R workflow developed during my Master 2 internship (Eco-epidemiology, University of Montpellier, Jan–Jul 2026) at Altopictus, within the MISArbO surveillance project.

> **Data notice.** The original MISArbO data belong to the project partners and are not published here.
> This repository contains the full analysis code and a **simulated dataset with the same structure**
> (`data/simulated/`), so that the modelling steps can be run and inspected.

## Question

Which environmental factors (weather, bird and vector indices, land cover) are associated with the probability of detecting West Nile virus (WNV) RNA in two environmental matrices: wetland water and mosquito excreta (xenomonitoring)?

## Data (original study)

- 812 samples, April–October 2025, 44 surveillance sites in Occitania (33 wetland-water sites, 11 xenomonitoring sites)
- 90 WNV-positive and 13 Usutu-positive samples (viral RNA detected by digital PCR)
- Covariates: ERA5-Land weather, Corine Land Cover, Bird Risk Index, VectorNet *Culex pipiens* layers

## Methods

- Data management with `dplyr`; covariates standardised (`scale()`), collinearity checked (VIF < 2)
- Binomial GLMMs (`lme4::glmer`) for detection probability, site as random effect
- Zero-inflated GLMMs with Tweedie distribution (`glmmTMB`) for viral RNA quantity
- Seasonality: natural cubic spline of day of year (`splines::ns`, 4 df); latitude/longitude as fixed effects
- Six models: weather, biotic and land-cover families, fitted separately per matrix
- Model checking with simulated residuals (`DHARMa`: uniformity, dispersion, outliers)

## Main finding

Detections were strongly structured by season (early for wetland water, later for xenomonitoring). After accounting for season, no weather or biotic variable was significantly associated with WNV detection probability. Usutu (n = 13) was too sparse to be modelled.

## Reproduce

```r
# 1. install the packages used in R/00_setup.R (dplyr, ggplot2, lme4, glmmTMB, DHARMa, broom.mixed, knitr, terra, sf, ...)
# 2. generate the synthetic dataset (same columns as the real DB_FULL)
source("R/00_simulate_data.R")   # writes data/simulated/DB_FULL_simulated.csv

# 3. render the Quarto report (runs on the simulated data)
# quarto::quarto_render("report/analysis.qmd")
```

Steps `01` and `02` (import of raw weather, bird-index, land-cover and raster files and
construction of `DB_FULL`) are provided to document the full pipeline but require the
original raw data. Modelling and diagnostics (`04_models_detection.R`) start from `DB_FULL`.
